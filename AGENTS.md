# Для ИИ-агентов

NotchDashboard — приложение для macOS, которое живёт в вырезе MacBook:
«уши» у выреза, мини-плеер при наведении, быстрый ввод и дашборд на весь
экран с задачами, фокус-таймером, музыкой, рабочими проектами, заметками,
буфером обмена и ИИ-ассистентом.

**Сейчас в репозитории нет кода**, только дизайн и спецификация.

## Что читать

1. `docs/SPEC.md` — что делаем: функционал каждого блока, горячие клавиши,
   разрешения, план. Пометка **[решить]** — вопрос открыт, спроси автора.
2. `docs/DESIGN.md` — дизайн-система текстом: цвета, шрифты, сетка главной,
   размеры блоков, параметры анимации.
3. `design/v2/` — актуальные макеты (PNG 2880 px) и их исходник `index.html`.
   Точные значения — в CSS этого файла.
4. `design/v1/` — первые листы. Музыка, состояния выреза, анимация раскрытия
   и настройки горячих клавиш актуальны. Главная v1 устарела, её заменяет v2.

## Правила

- Интерфейс на русском. Пишем коротко, как в макетах.
- Стек: Swift, SwiftUI + AppKit, macOS. Приложение без песочницы
  (нужны git, скрипты и `lsof`), распространяется вне App Store.
- Цвета, размеры и тайминги бери из `docs/DESIGN.md`, а не придумывай заново.
- Поменял дизайн — обнови `design/v2/index.html`, пересобери PNG
  (`NODE_PATH=$(npm root -g) node design/render.cjs`, нужен playwright)
  и поправь `docs/DESIGN.md`.
- Поменял функционал или принял решение по **[решить]** — обнови `docs/SPEC.md`.
- Не выдумывай ответы на открытые вопросы, спроси автора.
