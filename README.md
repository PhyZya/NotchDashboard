# NotchDashboard

Приложение для macOS, которое живёт в вырезе MacBook. Задачи, фокус-таймер,
музыка, рабочие проекты, заметки, буфер обмена и ИИ-ассистент — в «ушах»
выреза и в дашборде, который раскрывается из него на весь экран.

## Статус

Готов каркас (шаг 1 плана): «уши» у выреза, панель наведения с кнопкой ↗,
дашборд на весь экран с анимацией из выреза и пустыми блоками по сетке v3
в тёмной теме, `⌥D` из любого приложения. Блоки наполняются на следующих шагах.

## Сборка

Нужны macOS 27 и Xcode 27. Первый раз:

```sh
git clone https://github.com/PhyZya/NotchDashboard.git
cd NotchDashboard
scripts/run.sh
```

Работаем в одной ветке — основной, той, что на GitHub стоит по умолчанию.
`scripts/run.sh` сам подтягивает её свежую версию с GitHub (и переключается
на неё, если папка была на другой ветке), собирает приложение и запускает.
Если какие-то изменения лежат в другой ветке и в основную ещё не попали,
скрипт об этом предупредит.

```sh
scripts/run.sh                    # свежая версия с GitHub: собрать и запустить
scripts/run.sh --sample           # то же, панель наведения с музыкой и задачами
OFFLINE=1 scripts/run.sh          # без GitHub: собрать то, что в папке
swift run NotchDashboard          # запустить из терминала без .app
open Package.swift                # или открыть в Xcode и нажать Run
scripts/build-app.sh              # только собрать build/NotchDashboard.app
swift test                        # тесты логики (работают и в Linux)
```

Свои незакоммиченные правки скрипт не трогает и собирает как есть.
`scripts/build-app.sh` останавливает запущенную копию: у приложения нет
иконки в Dock, и `open` при работающей старой копии новую не запускает.
Какая сборка запущена, видно внизу меню по правому клику на вырезе:
ветка, коммит и время сборки.

Иконки в Dock нет. Наведите курсор на вырез — вытечет панель с музыкой
и горящими задачами. Дашборд на весь экран — кнопка ↗ в ней, `⌥D` или жест
двумя пальцами вниз по вырезу. Выйти — правый клик по вырезу или кнопка
настроек в дашборде. Тема по умолчанию тёмная, светлая включается в меню
кнопки настроек в шапке дашборда. На экране без выреза запускайте
с `--simulate-notch`, с музыкой и задачами из макета — с `--sample`,
в другой теме на один запуск — с `--theme light`.
