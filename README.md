# NotchDashboard

Приложение для macOS, которое живёт в вырезе MacBook. Задачи, фокус-таймер,
музыка, рабочие проекты, заметки, буфер обмена и ИИ-ассистент — в «ушах»
выреза и в дашборде, который раскрывается из него на весь экран.

## Статус

Готов каркас (шаг 1 плана): «уши» у выреза, раскрытие при наведении,
дашборд на весь экран с анимацией из выреза и пустыми блоками по сетке v2,
`⌥D` из любого приложения. Блоки наполняются на следующих шагах.

## Сборка

Нужны macOS 27 и Xcode 27.

```sh
swift run NotchDashboard          # запустить из терминала
open Package.swift                # или открыть в Xcode и нажать Run
scripts/build-app.sh              # собрать build/NotchDashboard.app
swift test                        # тесты логики (работают и в Linux)
```

Иконки в Dock нет. Дашборд — клик по вырезу, `⌥D` или жест двумя пальцами
вниз по вырезу. Выйти — правый клик по вырезу или кнопка настроек в дашборде.
На экране без выреза запускайте с `--simulate-notch`.
