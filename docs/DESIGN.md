# Дизайн-система NotchDashboard

Текстовая версия макетов, чтобы реализовывать без PNG. Точные значения
лежат в CSS файла `design/v2/index.html`. Если они расходятся с этим файлом,
главный — `index.html`.

## Блоки

- **Задачи.** Заголовок и ↗; «3 из 8 сделано» и недельный график (7 столбиков
  8 pt); полоска сегментов 5 pt; три плитки мониторинга; список с группами
  «Просрочено» и «Сегодня», строки 44 pt; кнопка «+ Добавить задачу ⌘K» 40 pt.
  Задача в фокусе — белая строка, в мете оранжевая точка и время.
- **Мини-приложения.** Сетка 4 × 2, иконка 42 pt со скруглением 13, подпись 11.
- **Музыка.** Обложка 80, мета «Сейчас играет · Spotify» с мини-эквалайзером,
  трек и артист, прогресс 4 pt, кнопки 36 / 46 / 36.
- **Работа.** Список проектов шириной 180 (строка 54, иконка 32) и белая
  карточка проекта: шапка с иконкой 42 и кнопкой «▶ Запустить», строки
  «Запуск», «Git» (+ последний коммит), «Ссылки», список скриптов (строка 32).
  Внизу строки «Localhost» (чипы 32) и «Инструменты» (иконки 36).
- **Ассистент.** Тёмная полоса, фиолетовый кружок 36, поле `#26262B` 44 pt, `⌘J`.
- **Фокус-таймер.** Шапка с точками помидоров; кольцо 144 слева; справа
  карточка задачи, готовые варианты 15/25/45/60 (28 pt) и кнопки
  (основная — градиент `#FFB547 → #FF5A4E`, «стоп» — кружок 36);
  внизу время на задачу и за день.
- **Заметки и закладки.** Карточка последней заметки `#FFEEB1` и две закладки
  (иконка 30 `ink` с жёлтой буквой).
- **Буфер обмена.** Индикатор «запись идёт», чипы-фильтры 24 pt, лента
  карточек 92 × 80 с подписью снизу, справа растворение.

## Движение

Из `design/v1/Состояния и движение.png`:

| Что | Параметры |
| --- | --- |
| Раскрытие в дашборд | 520 мс, cubic-bezier(0.32, 0.72, 0, 1); SwiftUI `.spring(response: 0.45, dampingFraction: 0.86)`, без отскока |
| Цвет формы | чёрный → `#E6E6EA` за 300 мс с задержкой 60 мс; при закрытии обратно в чёрный за 200 мс |
| Блоки | появление 280 мс с задержкой 160 мс: прозрачность 0 → 1, размытие 6 → 0, масштаб 0,985 → 1 |
| Закрытие | блоки гаснут за 100 мс, затем форма сжимается в вырез за 320 мс (ease-in-out) |
| Наведение | раскрытие через 150 мс; курсор ушёл — сворачивается сразу |
| Сохранение записи | панель втягивается в вырез, правое «ухо» 1,8 с показывает отметку и тип |
| Смена трека | «уши» на 2 с расширяются, та же пружина, что у раскрытия |

Таймер (из `design/v2/Фокус-таймер.png`):

| Что | Параметры |
| --- | --- |
| Уровень жидкости | оставшееся ÷ всё время, сдвиг раз в секунду за 800 мс, та же кривая |
| Волна | две синусоиды с периодом 58 pt: 2,4 с и 3,6 с навстречу, амплитуда 3,5 и 4,5; до старта 5 и 7 с |
| Пузырьки | 4 шт., всплывают на 46 pt за 3 с, только пока идёт |
| Кольцо | 6 pt, градиент `#FFD43B → #FF9F43 → #FF5A4E`, светящаяся точка на конце |
| Свечение | радиальное `#FF7A3D`, размытие 16, «дышит» 3,2 с |
| Пауза | насыщенность 100 → 35 % за 400 мс, волна стоит, цифры мигают раз в 1,6 с |
| Готово | жидкость уходит, круг заливается `ok`, вспышка 1,6 с |

В SwiftUI: `TimelineView(.animation)` + `Canvas` для волны, уровень через
`withAnimation`.
