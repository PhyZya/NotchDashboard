## Что поменялось

- **Тёмная тема по мотивам macOS.** Фон `#0B0B0D` сливается с вырезом, блоки
  `#1C1C1E`, строки и карточки `#2C2C2E`, выделенная строка `#3A3A3C`.
  Текст белый `#F5F5F7`, второстепенный и подписи — белый с прозрачностью 62 и 38 %.
- **Блоки без заливки цветом.** Задачи, заметки и буфер обмена больше не
  фиолетовые, жёлтые и синие, все блоки одного серого.
- **Кнопки внутри блоков серые** (`rgba(118,118,128,.24)`), как системные.
  В каждом блоке максимум одна светлая кнопка: «Запустить», пауза в плеере.
  Пресеты таймера и фильтры буфера — сегментированный контрол macOS.
- **Цвет остался только там, где он что-то значит:**
  - системный акцент `#0A84FF` — только «+ Запись»;
  - оранжевый `#FF9F0A` — фокус-таймер, задача в фокусе, приоритет `!!`, незакоммиченные файлы;
  - зелёный `#30D158` — запущено, чисто, запись идёт;
  - красный `#FF453A` — просрочено, ошибка;
  - музыка подсвечена цветом обложки.
- Иконки проектов, мини-приложений, инструментов и закладок одноцветные.

## Liquid Glass

Только на слое управления поверх контента, как советует Apple.
Сами блоки плотные, иначе текст хуже читается.

- Шапка: поиск, «+ Запись» (стекло с акцентом), настройки, закрыть.
- Музыка: блок подсвечен размытой обложкой, по краю блик стекла,
  кнопки ⏮ ⏭ стеклянные.
- Ассистент: плавающая стеклянная капсула внизу.
- Иконки мини-приложений и инструментов — «прозрачный» стиль иконок macOS.
- Шарик фокус-таймера: блик по краю, как у стекла.

В SwiftUI: `.glassEffect()`, для акцентной кнопки
`.glassEffect(.regular.tint(.accentColor))`, соседние элементы шапки —
в `GlassEffectContainer`.
